# WP 11.5c: Ask PersonalFi, reporting mode (`ask.compile` + `ask.narrate`)

**Request (Chris, verbatim).** 2026-10-25: "Good with the llm proposal but I want to expand askpersonalfi to cover being a financial advisor so come up with an expansion proposal there without requiring a fine tuned model." 2026-10-26: "Good with proposal." WP 11.5c is row 11.5c of `docs/research/12-ask-personalfi-advisor-expansion.md` §6 (the original 11.5 of `docs/research/11-llm-integration-design-proposal.md` §5): 11 §3.2's "model as a compiler, not an oracle", over 11.5b's `catalogue/1` and 11.5a's knowledge base.

**Result.**

1. **Two query types beside the narrator**, built on the explain / brief-narrate pattern: `ask.compile` (question → at most four catalogue calls with typed arguments, or `unanswerable` with a real nearest screen) and `ask.narrate` (the results → at most four sentences, ≤ 900 characters). Each has its own manifest under the narrator's scope bound, its own payload preview and approval in Advisor management, the kill ladder (levels 1–4), one `advisor_runs` row per model call with the payload retained for the run inspector, and a consent text per step (`ask-consent/1`, its sha256 inside the approvable shape).
2. **The run.** `POST /ask` runs the deterministic pre-check, writes an `ask_sessions` row and enqueues `insights.ask`; **the api never calls a model**. The worker compiles, runs the calls in process through `callCatalogueByName` (11.5b's gate re-reads the grant), and narrates, **one model call per step** (each step claimed on the row, under the advisor lock, before its call). Migration `0060_ask_sessions` (expand-only).
3. **Refusals by name.** Instruction text, a `MERCHANT_…` token or markup in the question → `refused` (`question.*`), no model asked; security selection, market timing, tax filing, insurance, estate and execution ("go ahead and move it") → `unanswerable` / `out_of_scope` with a nearest screen, no model asked; nothing a granted function computes → "I can't compute that yet — here is the nearest screen"; a compile reply the validator refuses → `compile.*`; a narration it refuses → `narrate.*` and **the arithmetic without the prose** (never nothing).
4. **`/ask`** (nav: Overview, after Insights; the mobile More sheet): the provider + model badge, "AI-assisted wording", the app's own "I looked at: …" line (each item expandable to its figures), the 07 §7.2 disclaimer, the history, and the unavailable state linking to Advisor management.
5. **The fifteenth self-test check, `ask_grounding`.**
6. **`--ask` in `scripts/advisor-eval.ts`**: a 64-question compile golden set, precision/recall per catalogue function.
7. **Red team**: `apps/api/test/redteam-ask.test.ts`, the seven probes.
8. **Docs**: RUNBOOK "Ask PersonalFi (v0.9.23)", release notes `## v0.9.23`, pointers in 11 §5 row 11.5 and 12 §6 row 11.5c.

**No live model was called.** Every model in this package's tests is the Ollama fake or the hosted vendor fake.

**State of the tree.** Uncommitted. HEAD was `d12b731` when I started and is `51a645f` now (the orchestrator's own commits in between); nothing is staged by this WP. The 16 phase-10 PNGs (4 modified `wp10.3-*.png`, 12 untracked `wp3.11-*.png`) are **not mine, untouched**.

**How it was built.** I wrote the migration, the context, the adapters, the composition, the routes, the self-test, the eval, the red team, the api-db tests and the docs. One Sonnet-tier web fork built `/ask` (apps/web only) while I worked on the backend; I then fixed two control-check count pins it had not run (`narrator-settings.spec.ts`).

### 1.2 The status machine

```
POST /ask ─ pre-check ─┬─ refused (question.*)            ┐ finished at once,
                       ├─ unanswerable (out_of_scope)     ┘ no model, no job
                       └─ compiling ─ claim compile run ─ compile call
                            ├─ refused (compile.*) / unanswerable (model verdict) / failed / cancelled
                            └─ running ─ catalogue calls (in process, under the grant)
                                 ├─ unanswerable (not_computable: no call answered ok)
                                 └─ narrating ─ claim narrate run ─ narrate call
                                      └─ shown | refused (narrate.*, results kept) | failed | cancelled
```

A gate refusal at either step (an approval withdrawn, a switch off) finishes `failed` with the reason. A pass that finds a step already claimed asks nothing; a claimed session older than both deadlines plus five minutes is closed `failed` (`step_interrupted`).

## 5. Migration

`0060_ask_sessions.sql`, expand-only, references only `users`; CHECKs in the 0059 style (each outcome whole or not at all, lengths, the refusal pattern, the provider enum, the step claims whole). Listed in `packages/db/test/migrate.test.ts`, claimed in `OWNERSHIP.md`, exempt from the export (`registry.ts`), named in the soak canary's `NOT_READ_BY_THE_REPORT`.

```sql
CREATE TABLE ask_sessions (
  id                    UUID         PRIMARY KEY,
  user_id               UUID         NOT NULL REFERENCES users (id) ON DELETE CASCADE,
  question              TEXT         NOT NULL
                                     CONSTRAINT ask_sessions_question_check
                                     CHECK (char_length(question) BETWEEN 1 AND 500),
  status                TEXT         NOT NULL
                                     CONSTRAINT ask_sessions_status_check
                                     CHECK (status IN ('compiling', 'running', 'narrating', 'shown',
                                                       'refused', 'unanswerable', 'failed', 'cancelled')),
  catalogue_version     TEXT         NOT NULL
                                     CONSTRAINT ask_sessions_catalogue_version_check
                                     CHECK (catalogue_version ~ '^catalogue/[1-9][0-9]{0,3}$'),
  compiled_calls        JSONB        CONSTRAINT ask_sessions_calls_check
                                     CHECK (compiled_calls IS NULL
                                            OR (jsonb_typeof(compiled_calls) = 'array'
                                                AND jsonb_array_length(compiled_calls) <= 4)),
  results               JSONB        CONSTRAINT ask_sessions_results_check
                                     CHECK (results IS NULL
                                            OR (jsonb_typeof(results) = 'array'
                                                AND jsonb_array_length(results) <= 4)),
  narration_text        TEXT         CONSTRAINT ask_sessions_narration_check
                                     CHECK (narration_text IS NULL OR char_length(narration_text) BETWEEN 1 AND 900),
  refusal               TEXT         CONSTRAINT ask_sessions_refusal_check
                                     CHECK (refusal IS NULL OR refusal ~ '^(question|compile|narrate)\.[a-z][a-z_.]{0,47}$'),
  unanswerable_reason   TEXT         CONSTRAINT ask_sessions_unanswerable_check
                                     CHECK (unanswerable_reason IS NULL
                                            OR unanswerable_reason IN ('out_of_scope', 'not_computable')),
  unanswerable_topic    TEXT         CONSTRAINT ask_sessions_topic_check
                                     CHECK (unanswerable_topic IS NULL OR unanswerable_topic ~ '^[a-z][a-z_]{0,31}$'),
  nearest_screen        TEXT         CONSTRAINT ask_sessions_nearest_screen_check
                                     CHECK (nearest_screen IS NULL OR nearest_screen ~ '^/[a-z0-9/-]{0,63}$'),
  error_code            TEXT         CONSTRAINT ask_sessions_error_code_check
                                     CHECK (error_code IS NULL OR error_code ~ '^[a-z][a-z0-9_.:-]{0,63}$'),
  llm_provider          TEXT         CONSTRAINT ask_sessions_provider_check
                                     CHECK (llm_provider IS NULL
                                            OR llm_provider IN ('ollama', 'openai', 'openrouter', 'anthropic')),
  llm_model             TEXT         CONSTRAINT ask_sessions_model_check
                                     CHECK (llm_model IS NULL OR char_length(llm_model) BETWEEN 1 AND 200),
  compile_run_id        UUID,
  narrate_run_id        UUID,
  compile_input_digest  TEXT         CONSTRAINT ask_sessions_compile_digest_check
                                     CHECK (compile_input_digest IS NULL OR compile_input_digest ~ '^sha256:[0-9a-f]{64}$'),
  narrate_input_digest  TEXT         CONSTRAINT ask_sessions_narrate_digest_check
                                     CHECK (narrate_input_digest IS NULL OR narrate_input_digest ~ '^sha256:[0-9a-f]{64}$'),
  knowledge_read        JSONB        CONSTRAINT ask_sessions_knowledge_read_check
                                     CHECK (knowledge_read IS NULL OR jsonb_typeof(knowledge_read) = 'object'),
  compile_ms            INTEGER      CONSTRAINT ask_sessions_compile_ms_check
                                     CHECK (compile_ms IS NULL OR compile_ms >= 0),
  calls_ms              INTEGER      CONSTRAINT ask_sessions_calls_ms_check
                                     CHECK (calls_ms IS NULL OR calls_ms >= 0),
  narrate_ms            INTEGER      CONSTRAINT ask_sessions_narrate_ms_check
                                     CHECK (narrate_ms IS NULL OR narrate_ms >= 0),
  created_at            TIMESTAMPTZ  NOT NULL DEFAULT now(),
  finished_at           TIMESTAMPTZ,

  -- Each outcome whole or not at all.
  CONSTRAINT ask_sessions_shown_whole
    CHECK ((status = 'shown') = (narration_text IS NOT NULL)),
  CONSTRAINT ask_sessions_refused_whole
    CHECK ((status = 'refused') = (refusal IS NOT NULL)),
  CONSTRAINT ask_sessions_unanswerable_whole
    CHECK ((status = 'unanswerable') = (unanswerable_reason IS NOT NULL)
           AND (unanswerable_reason IS NULL) = (nearest_screen IS NULL)
           AND (unanswerable_topic IS NULL OR unanswerable_reason = 'out_of_scope')),
  CONSTRAINT ask_sessions_error_whole
    CHECK ((status IN ('failed', 'cancelled')) = (error_code IS NOT NULL)),
  CONSTRAINT ask_sessions_model_together
    CHECK ((llm_provider IS NULL) = (llm_model IS NULL)),
  -- A step's run is claimed with its digest and the model it asked.
  CONSTRAINT ask_sessions_compile_claim_whole
    CHECK ((compile_run_id IS NULL) = (compile_input_digest IS NULL)
           AND (compile_run_id IS NULL OR llm_provider IS NOT NULL)),
  CONSTRAINT ask_sessions_narrate_claim_whole
    CHECK ((narrate_run_id IS NULL) = (narrate_input_digest IS NULL)
           AND (narrate_run_id IS NULL OR compile_run_id IS NOT NULL)),
  CONSTRAINT ask_sessions_narration_has_run
    CHECK (narration_text IS NULL OR (narrate_run_id IS NOT NULL AND results IS NOT NULL)),
  CONSTRAINT ask_sessions_results_after_compile
    CHECK (results IS NULL OR compiled_calls IS NOT NULL),
  CONSTRAINT ask_sessions_finished
    CHECK ((status IN ('compiling', 'running', 'narrating')) = (finished_at IS NULL))
);

CREATE INDEX ask_sessions_user_created_idx
  ON ask_sessions (user_id, created_at DESC, id DESC);
```
