#        pip download --only-binary=:all: -d amd64 yfinance
#      which resolves the closure for musllinux x86_64;
#   2. the same pins for arm64, without resolving again:
#        pip download --no-deps --only-binary=:all: --platform musllinux_1_2_aarch64 \
#          --python-version 3.15 --implementation cp -d arm64 -r pins.txt
#   3. `pip hash -a sha256` on every file in both directories, one --hash per file.
